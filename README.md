# Dr. Diffie

Die humorvolle Praxisseite des Dackels Diffie, der sich für einen Tierarzt hält.
Diffie hat keine Approbation. Alles auf der Seite ist ein Scherz.

Live: https://dev.lecmich.it/drdiffie/

## Entwicklung

    npm install
    npm run dev    # http://localhost:3000/drdiffie/
    npm run qa     # Build und Screenshots in qa/

Veröffentlichen auf dem Dev-Server: `npm run veroeffentlichen`

Texte der Seite stehen in `src/app/page.tsx`, die Rezepte in `src/components/rezept.tsx`.
Weitere Regeln stehen in `CLAUDE.md`.
